Every Saturday morning, at the same time, a primatologist goes and sits in the forest to listen for titi monkey calls, counting the number of calls they hear in a 2 hour window from 5am to 7am. Based on previous knowledge, she believes that the mean number of calls she will hear in that time is exactly 15. Let X represent the appropriate Poisson random variable of the number of calls heard in each monitoring session.

🐒 Question 1: What is the probability that she will hear more than 8 calls during any given session?

lambda <- 15
prob_more_than_8 <- 1 - ppois(8, lambda)
print(paste("Probability of hearing more than 8 calls is:", round(prob_more_than_8, 4)))
[1] "Probability of hearing more than 8 calls is: 0.9626"

Rounding and adding text to the response are great touches

🐒 Question 2: What is the probability that she will hear no calls in a session?

prob_no_calls <- dpois(0, lambda)
print(paste("Probability of hearing no calls is:", round(prob_no_calls, 4)))
[1] "Probability of hearing no calls is: 0"

🐒 Question 3: What is the probability that she will hear exactly 3 calls in a session?

prob_exactly_3 <- dpois(3, lambda)
print(paste("Probability of hearing exactly 3 calls is:", round(prob_exactly_3, 4)))
[1] "Probability of hearing exactly 3 calls is: 2e-04"

🐒 Question 4: Plot the relevant Poisson mass function over the values in range 0 ≤ x ≤ 30.

# Create data frame for ggplot
pmf_data <- data.frame(
  x = 0:30,
  probability = dpois(0:30, lambda)
)

# Create plot using ggplot2
ggplot(pmf_data, aes(x = x, y = probability)) +
  geom_col(fill = "orange", alpha = 0.7) +
  labs(title = "Poisson Distribution (λ = 15)",
       x = "Number of Calls",
       y = "Probability") +
  theme_minimal() +
  scale_x_continuous(breaks = seq(0, 30, by = 5))

I really like the design of your histogram!

🐒 Question 5: Simulate 104 results from this distribution (i.e., 2 years of Saturday monitoring sessions).
